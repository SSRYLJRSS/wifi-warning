# WiFiWarning v2.0 — 交互与视觉规范（UX Spec）

## 1. 设计原则
- **一屏可达**：单页应用（SPA），左侧固定导航 + 右侧内容，**禁止页面来回跳转**。所有操作原地完成（抽屉/行内编辑/Toast）。
- **状态优先**：顶部常驻“当前网络”实时状态条，任何页面都能看到 WiFi/以太网 现状。
- **克制而有质感**：苹果式“机械精密”= 高对比、精确留白、细边框、单一强调色、微动效；拒绝花哨渐变与“AI 味”堆砌。
- **即时反馈**：所有按钮 120–180ms 反馈，危险操作二次确认，结果 Toast。

## 2. 信息架构（左侧导航，5 项）
1. **概览 Overview** — 实时状态 + 快捷开关
2. **拦截规则 Rules** — 网络→软件组 规则
3. **软件组 Groups** — 应用分组管理
4. **动态 Activity** — 拦截/网络事件时间线
5. **设置 Settings** — 通用/安全/高级/关于
底部固定：防护总开关 + 版本。

## 3. 页面规格

### 3.1 概览
- **主状态卡**：左“WiFi”块（SSID、信号 4 格、已连接/未连接），右“以太网”块（网卡名、已连接/已断开）。实时小圆点呼吸动效。
- **快捷操作**（大号触感按钮，带当前状态）：
  - 禁用 WiFi / 启用 WiFi
  - 禁用以太网 / 启用以太网
  - 恢复上次禁用的连接（secondary）
- **防护开关** 大开关 + 说明。
- 小统计：今日拦截 N 次 / 本周 N 次。

### 3.2 拦截规则
- 规则卡列表：`网络 → 软件组`，右侧启用开关 + 编辑/删除。
- “新建规则”：行内抽屉，三步（选网络 combobox 来自实时网络+手动 / 选软件组 / 确认），保存即生效。
- 空态引导：说明“连接到该网络时，被管控软件启动前会经提醒页”。

### 3.3 软件组
- 组卡：组名 + 应用 chips（图标+名），添加应用（系统文件选择 .exe/.lnk）、删除、重命名。

### 3.4 动态
- 过滤（全部/拦截/放行/网络变更）+ 表（时间 / 网络 / 应用 / 结果）。
- 顶部 3 指标：今日拦截 / 本周 / 最常受限。

### 3.5 设置
- 通用：开机启动、语言（中/英）、主题（深/浅）、服务端口。
- 安全：放行密码、放行时长。
- 高级：拦截方式（IFEO / 快捷方式）状态与开关、一键恢复快捷方式、提权说明。
- 关于：版本、许可证、GitHub、配置/备份路径。

## 4. 托盘右键菜单（对应“托盘一键恢复”）
- 当前网络: WiFi SSID · 以太网 名称（禁用信息项）
- ─
- 禁用 WiFi / 启用 WiFi
- 禁用以太网 / 启用以太网
- **恢复上次禁用的连接**
- ─
- 防护: 开启/关闭
- 打开控制面板
- 退出

## 5. 设计令牌（Design Tokens）
- 深色（默认）：`--bg:#0B0E14; --surface:#121722; --surface-2:#171E2B; --border:rgba(255,255,255,.08); --text:#E8EDF5; --text-2:#9AA7BD; --muted:#5E6B82`
- 强调：`--accent:#4F8CFF` → `--accent-2:#38BDF8`（渐变仅用于强调按钮/状态）；成功 `#34D399`、警告 `#FBBF24`、危险 `#F87171`
- 浅色：`--bg:#F5F7FB; --surface:#FFFFFF; --border:rgba(15,23,42,.08); --text:#0F172A`
- 字体：`"Segoe UI Variable","Segoe UI","Microsoft YaHei UI",-apple-system,system-ui,sans-serif`；中文回退 Microsoft YaHei UI。
- 字号：Display 32/700、H1 22/650、Body 14/500、Caption 12/500。
- 圆角：卡片 16、控件 10、胶囊 999。间距 4/8 基。阴影轻、1px 发丝边框。动效 140ms ease-out。
- 布局：左栏 240px；内容最大宽 1080 居中；顶部状态条 56px 玻璃模糊。

## 6. 交互约定
- 禁用网络/删除规则等破坏性操作 → 确认弹层。
- 所有网络启停 → 结果 Toast（成功/失败原因），失败给出可操作提示（如“需要管理员/被杀软拦截”）。
- 语言/主题切换即时生效并持久化。
- 无横向滚动；窄窗自适应（≥900px 左栏收窄为图标）。
